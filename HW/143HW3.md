## ตัวอย่าง Class 3 ประเภท

### a) Utility Class

**ตัวอย่าง:** `System.Math`  
**ลิงก์:** [System.Math Documentation](https://learn.microsoft.com/en-us/dotnet/api/system.math?view=net-10.0)

**คำอธิบาย:**
- Math เป็น **static class** ที่ไม่สามารถสร้าง instance ได้
- ประกอบด้วย methods และ constants ทางคณิตศาสตร์ เช่น `Abs()`, `Sqrt()`, `Pow()`, `PI`
- ใช้งานโดยเรียกผ่านชื่อ class โดยตรง เช่น `Math.Sqrt(25)`
- **เหตุผลที่เป็น Utility Class:**
  - มี methods ที่เป็น static ทั้งหมด
  - ไม่มี state (ไม่เก็บข้อมูลภายใน)
  - ทำหน้าที่เป็นเครื่องมือช่วยในการคำนวณ

**ตัวอย่างการใช้งาน:**
```csharp
double result = Math.Sqrt(144);  // ผลลัพธ์: 12
double power = Math.Pow(2, 3);   // ผลลัพธ์: 8
Console.WriteLine(Math.PI);       // ผลลัพธ์: 3.14159...
```

### b) Mutable Class

**ตัวอย่าง:** `System.Text.StringBuilder`  
**ลิงก์:** [StringBuilder Documentation](https://learn.microsoft.com/en-us/dotnet/api/system.text.stringbuilder?view=net-10.0)

**คำอธิบาย:**
- StringBuilder ใช้สำหรับจัดการและแก้ไขข้อความได้โดยไม่สร้าง object ใหม่ทุกครั้ง
- **สามารถเปลี่ยนแปลงข้อมูลภายใน (mutable)** ได้หลังจากสร้าง instance แล้ว
- มี methods เช่น `Append()`, `Insert()`, `Replace()`, `Remove()` ที่แก้ไขข้อความได้
- **เหตุผลที่เป็น Mutable Class:**
  - สามารถเปลี่ยนค่า internal state ได้ตลอดเวลา
  - ไม่สร้าง object ใหม่เมื่อมีการแก้ไข (ต่างจาก string ที่เป็น immutable)
  - ประหยัด memory เมื่อต้องต่อข้อความหลายครั้ง

**ตัวอย่างการใช้งาน:**
```csharp
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World");     // เปลี่ยนเป็น "Hello World"
sb.Insert(5, ",");       // เปลี่ยนเป็น "Hello, World"
sb.Replace("World", "C#"); // เปลี่ยนเป็น "Hello, C#"
Console.WriteLine(sb.ToString()); // ผลลัพธ์: "Hello, C#"
```

### c) Immutable Class

**ตัวอย่าง:** `System.DateTime`  
**ลิงก์:** [DateTime Documentation](https://learn.microsoft.com/en-us/dotnet/api/system.datetime?view=net-10.0)

**คำอธิบาย:**
- DateTime เก็บข้อมูลวันที่และเวลา
- **ไม่สามารถเปลี่ยนแปลงค่าได้หลังจากสร้าง (immutable)**
- การดำเนินการใดๆ จะคืนค่าเป็น DateTime object ใหม่เสมอ
- **เหตุผลที่เป็น Immutable Class:**
  - ค่าภายในไม่สามารถแก้ไขได้หลังจากสร้าง
  - Methods เช่น `AddDays()`, `AddHours()` จะ return object ใหม่ ไม่แก้ไข object เดิม
  - ปลอดภัยในการใช้งานแบบ multi-threading
  - ป้องกันข้อผิดพลาดจากการแก้ไขค่าโดยไม่ตั้งใจ

**ตัวอย่างการใช้งาน:**
```csharp
DateTime today = DateTime.Now;
DateTime tomorrow = today.AddDays(1);  // สร้าง object ใหม่

Console.WriteLine(today);      // วันที่เดิมไม่เปลี่ยน
Console.WriteLine(tomorrow);   // วันที่ใหม่ +1 วัน

// today ยังคงเป็นค่าเดิม แสดงว่า DateTime เป็น immutable
```

## สรุปความแตกต่าง

| ประเภท | ลักษณะ | ตัวอย่าง | การเปลี่ยนแปลงข้อมูล |
|--------|--------|----------|---------------------|
| **Utility Class** | Static methods, ไม่มี state | `Math` | ไม่มีข้อมูลให้เปลี่ยน (ไม่มี instance) |
| **Mutable Class** | แก้ไขข้อมูลภายในได้ | `StringBuilder` |  เปลี่ยนแปลงได้ (object เดิม) |
| **Immutable Class** | ไม่สามารถแก้ไขข้อมูลได้ | `DateTime` | เปลี่ยนไม่ได้ (สร้าง object ใหม่) |

---

##  สรุป

1. **Utility Class (Math)** - ใช้เป็นเครื่องมือช่วยทำงาน ไม่ต้องสร้าง instance
2. **Mutable Class (StringBuilder)** - ประหยัด memory เมื่อต้องแก้ไขข้อมูลบ่อย
3. **Immutable Class (DateTime)** - ปลอดภัย ป้องกันการแก้ไขโดยไม่ตั้งใจ
